# @open-agent-docs/db

[Open Agent Docs](https://github.com/kadaliao/open-agent-docs) 数据库的计算引擎（WASM）：筛选、排序、分组、公式、汇总，和服务器同一份 Rust 代码。
一般不用直接装：`@open-agent-docs/client` 的 `client.database(id)` 用它在本地算，`@open-agent-docs/editor` 的数据库视图也用它。

The Open Agent Docs database engine as WASM (filters, sorts, groups, formulas, totals), the same Rust code as the server.
You normally get it through `@open-agent-docs/client` (`client.database(id)`) rather than installing it directly.

# @open-agent-docs/db

English | [简体中文](https://github.com/kadaliao/open-agent-docs/blob/main/packages/db-wasm/README.zh-CN.md)

The [Open Agent Docs](https://github.com/kadaliao/open-agent-docs) database engine as WASM: filters, sorts, groups, formulas and totals, the same Rust code as the server.
You normally don't install it directly: `client.database(id)` in `@open-agent-docs/client` uses it to compute locally, and so do the database views in `@open-agent-docs/editor`.

More: [Embedding in your own app](https://github.com/kadaliao/open-agent-docs/blob/main/docs/en/embedding.md) ([简体中文](https://github.com/kadaliao/open-agent-docs/blob/main/docs/zh/embedding.md))
